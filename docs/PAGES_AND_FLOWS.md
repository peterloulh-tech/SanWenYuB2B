# 页面清单与演示链路

## 当前已有页面

| 模块 | 路由 | 当前用途 |
| --- | --- | --- |
| 首页 | `/` | 交易入口、行情、现货、采购需求、供应商 |
| 产品大厅 | `/products` | B2B 现货商品列表 |
| 商品详情 | `/products/:id` | 商品信息、询价和直接采购入口 |
| 采购大厅 | `/procurement` | 采购需求列表 |
| 报价对比 | `/procurement/:id` | 多供应商报价比较 |
| 确认订单 | `/procurement/:id/confirm` | 采购、交付和金额确认 |
| 市场行情 | `/market` | 价格、成交量和热门需求展示 |
| 供应商 | `/suppliers` | 认证供应商展示 |
| 产业服务 | `/services` | 加工、包装、检测、仓储、冷链和船运服务列表 |
| 服务详情 | `/services/:id` | 服务能力、计价说明和需求提交 |
| 服务需求结果 | `/services/request/success` | 静态演示需求提交结果 |
| 订单中心 | `/services/orders` | 订单列表和状态入口 |
| 订单履约 | `/services/orders/:id` | 冷链、物流、称重和单据展示 |
| 供应链金融 | `/finance` | 金融产品演示与申请入口 |
| 帮助中心 | `/help` | 使用说明和联系方式 |
| 运营后台 | `/operations` | 运营工作台静态展示 |
| 数据大屏 | `/data-screen` | 管理层产业数据展示 |
| 移动端首页 | `/mobile` | 移动端演示入口 |
| 移动交易中心 | `/mobile/trade` | 移动端采购和供应服务入口 |

此外还有登录、注册、发布采购、报价、供应商主页和金融申请等演示表单路由。

## 当前主要业务链路

### 现货采购

首页/产品大厅 → 商品详情 → 提交询价或直接采购 → 确认订单。

### 采购需求与报价

采购大厅 → 采购需求详情/报价对比 → 选择供应商 → 确认订单。

### 订单履约

订单中心 → 订单履约详情 → 查看物流、冷链温度、称重和单据。

### 辅助展示

首页 → 市场行情 / 供应商 / 供应链金融 / 运营后台 / 数据大屏。

## 计划新增链路

### B2C 消费零售

统一门户 → 消费零售频道 → 零售商品列表 → 商品详情 → 购物车/确认订单 → 下单结果。

### 产业服务交易

服务大厅 → 服务详情 → 发布服务需求/立即咨询 → 服务确认结果。

### 全产业链供应与采购

产业链分类 → 商品或服务列表 → 详情 → 询价/采购/发布需求。

### 新闻政策

资讯首页 → 新闻/政策列表 → 详情 → 原文来源。

## 页面处理原则

- 优先补齐业务链路，不一次性铺满所有页面。
- 新页面开发时，顺带整理被修改到的旧页面。
- 每完成一条链路，再决定下一条链路的范围。
