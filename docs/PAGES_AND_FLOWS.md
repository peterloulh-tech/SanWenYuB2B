# 页面清单与演示链路

## 公网演示入口

- 固定地址：`https://peterloulh-tech.github.io/SanWenYuB2B/`，由 GitHub Pages 托管，不依赖本机开机或本地服务。
- 公网基础路径为 `/SanWenYuB2B/`；下表中的既有业务路由均在该基础路径下保持原链路，例如商品详情为 `/SanWenYuB2B/products/:id`，运营大屏为 `/SanWenYuB2B/data-screen`。
- 生产构建提供 `404.html` 单页应用回退，直接打开或刷新详情路由仍可进入对应页面。
- 公开仓库只包含生产构建文件；本地开发与固定本地地址继续使用原有根路径，不改变页面入口和业务操作。

## 当前主要业务链路

### 现货采购

首页热门现货/产品大厅 → 商品详情 → 提交询价或直接采购 → 确认订单。

首页热门现货从统一企业商品库选取 8 项商品，以两组卡片从右向左无缝循环；卡片展示名称、产品产地、产品形态、规格和参考价，悬停或键盘聚焦时暂停，并进入数据一致的商品详情。减少动态效果时停止自动滚动并保留首组手动浏览。

### 企业商品浏览

企业首页“养殖供应 / 深加工品 / 其他海产” → 统一企业商品大厅（自动选中对应分区）→ 每页浏览最多 8 项四列两行图文商品 → 使用页码继续浏览，或按商品、品种、产品产地、供应商和商品分区筛选 → 商品详情 → 询价或发布采购需求。四张快捷卡可全部不选并显示综合结果；分类或搜索变化时回到第 1 页。细分类位于商品名称行右端；四个浅色详情块内的字段左对齐、冒号固定对齐，红框信息使用 12—14px 字号并适度压缩详情与按钮间距，顶部图片尺寸和卡片整体样式保持不变。

当前四个分区保持不变：鲜鱼产品增加虹鳟整鱼；养殖供应将鱼卵和鱼苗拆开，并分别展示挪威、美国种源；其他海产增加人工养殖海马干品和西施舌。产品产地/种源国家与供应商所在地在卡片和详情中分开展示。

“我要采购”默认进入鲜鱼产品；鲜鱼销售和采购需求继续由“我要卖鱼”“我要找货”和采购大厅承接，不额外占用快捷卡片。

### 硅小智语音搜索

首页、商品大厅、供应商大厅、产业服务、采购大厅、订单履约中心或个人消费首页 → 点击硅小智 → 点击“开始语音搜索”并授权浏览器麦克风 → 说出本页要查的商品、服务、企业或订单 → 浏览器输出最终识别文字 → 写入当前搜索栏并自动显示本页综合结果 → 可点击分类或状态继续收窄。

硅小智入口采用上图下签，人物不被文字牌覆盖；可拖拽并在松手后吸附最近的浏览器左侧或右侧，跨页面保留当前会话位置。首页关键词进入 `/products?section=all`；商品大厅 URL 保留综合分区和关键词。无语音、权限拒绝、无麦克风、网络错误或浏览器不支持时显示可恢复提示，用户继续使用原搜索栏。当前不覆盖移动端、详情页、表单页、运营后台和数据大屏，也不提供多轮对话或后端 AI。

### PC 搜索栏

首页、企业商品大厅、供应商大厅、产业服务大厅、采购需求大厅、订单履约中心和个人消费首页统一使用首页基线的连体搜索栏：白色输入区和蓝色搜索按钮共用蓝色边框与 8px 圆角，控件高 45px，按钮宽 84px，输入区与按钮之间无间隙。首页输入区右边界与标题文字右缘对齐，搜索按钮可继续向右伸出；商品和服务大厅的发布类按钮保持独立。搜索关键词、筛选组合、语音写入和既有跳转不变；移动端和未挂载路由的旧页面不在本批范围。

### 采购需求与报价

首页/商品大厅/商品详情/采购大厅 → 发布采购需求 → 选择唯一完整品类路径并填写采购与联系信息 → 校验通过后显示本页演示成功状态 → 返回采购大厅或继续发布。

采购大厅 → 采购需求详情/报价对比 → 选择供应商 → 确认订单。

### 产业服务交易

产业服务大厅 → 服务详情 → 提交服务需求 → 提交成功。

### 供应商浏览

首页或顶部导航 → 供应商大厅 → 查看 19 家去重综合目录，或切换鲜鱼产品、养殖供应、深加工品或其他海产 → 在标题横幅跨分类搜索企业、地区、主营品类或代表商品 → 必要时再按分类收窄 → 企业主页。

供应商目录直接从统一企业商品库按“供应商 + 分区”聚合，四分类分别为 5、6、3、6 家。综合状态把跨分类企业合并为一张卡并合并主营品类和代表商品；分类状态仍显示对应分类记录。不增加“全部供应商”卡，四卡全不选即为综合状态。分类、搜索和空状态均为本地前端演示，不请求后端数据。

### 订单履约

订单中心 → 订单履约详情 → 查看物流、冷链温度、称重和单据。

### 消费零售

统一门户页头“企业交易 / 个人消费”常驻频道切换 → 个人消费首页 → 零售商品详情 → 购物车 → 确认订单 → 下单结果。

该链路仅演示商品浏览、数量和金额传递、收货信息校验与静态下单结果，不创建真实订单、不扣减库存、不发起支付。

公共页头的频道切换位于品牌右侧：企业页面选中“企业交易”，个人消费及其详情、购物车、确认订单和下单结果页面选中“个人消费”。频道使用实色分段选中块，右侧频道内主导航使用文字与底部线表示当前页面。

### 辅助展示

顶部导航 → 市场行情；首页 → 供应商 / 供应链金融 / 运营后台。

顶部导航 → 市场行情 → 使用三个业务条件和数据日期查看当日均价、成交量与采购需求，虹鳟与银鲑分别产生独立演示行情 → 使用同一组业务条件切换 7/30/90 日 ECharts 成交价格走势并悬浮查看每日价格 → 查看大字号平台演示采购需求滚动快讯与单行全平台供需指标 → 查看采购大厅。数据日期不改变走势图，所有行情和滚动采购需求均为本地平台演示数据。

企业页面右上角“运营大屏” → 数据大屏 → 查看高对比 KPI、实时成交播报、全国交易流向、匹配产地数据的热门产地 TOP5、销售地区与重点采购商排行、订单履约状态环形图 → 悬浮查看近30日成交均价折线图和交易额柱状图 → 查看重新分配文字、总量与比例条空间的热门规格需求 TOP5，以及右下角每约 2.8 秒循环更新的三条大字号单行演示供求信息；公共页脚“帮助中心” → 帮助中心。

### 新闻政策与行业资讯

企业首页“新闻政策” → 资讯中心 → 横幅中切换“综合 / 国家政策 / 时事新闻 / 行业资讯” → 双列分页列表 → 详情 → 原文来源说明。当前收录 5 条国家政策、5 条时事新闻和微信公众号“壹渔业”最近 20 篇行业资讯；前两类使用国内官方网站并提供原文链接，公众号内容保留微信内检索说明。
