# 项目介绍

## 一句话定位

以日照、青岛为产业中心，以三文鱼全产业链为核心，逐步覆盖其他海产品的 B2B + B2C 数字化交易与产业服务平台。

## 建设背景

平台希望发挥日照、青岛的海洋渔业、港口、加工和冷链资源优势，连接产业链上下游主体，改善供需分散、价格信息不透明、履约过程不可见和产业数据难沉淀等问题。

项目不是单纯的零售商城。它需要同时展示：

- 商品买卖。
- 加工、包装、检测、仓储、冷链和运输等服务交易。
- 供应信息和采购需求的发布与匹配。
- 市场行情、新闻政策和项目进展。
- 订单履约、运营管理和产业数据展示。

## 当前阶段

当前处于前期方案与 UI 演示阶段，主要目标是快速制作 PC 静态页面，并用简单点击跳转串起业务流程。

本阶段关注：

- 页面是否清楚表达业务。
- 主要按钮是否可点击并能进入下一步。
- 关键业务链是否完整、容易讲解。
- 不同页面是否保持统一品牌和视觉风格。

本阶段暂不关注真实后端、真实支付、复杂权限、IoT 接入、正式金融审批及生产级运维体系。

## 主要用户

- 养殖场和供应企业负责人。
- 食品加工、餐饮、商超和批发采购企业。
- 包装、检测、仓储、冷链、船运等产业服务商。
- 普通消费者。
- 平台运营人员和管理层。

其中大量产业用户年龄在 40 岁以上，因此易理解、易操作优先于信息密度和炫技效果。

## 产品结构方向

- 统一品牌门户。
- 企业交易频道：面向 B2B 商品、服务、询报价、合同与履约。
- 消费零售频道：面向 B2C 小包装成品、购物车、零售订单与个人售后。
- 企业交易内部再区分采购方、供应方和服务商身份。
- 两个频道可以共享品牌、供应商和基础商品资料，但价格、起订量、结算与订单流程分开。
