# 简要项目汇报模板

## 本轮完成

- 列出 1～4 项实际完成内容。

## 验证结果

- 构建、关键跳转或页面检查结果。

## 待确认 / 风险

- 只列需要用户决定或会影响下一步的问题；没有则写“无”。

## 下一步

- 推荐继续推进的一项工作。

## Dashi 任务结论模板

任务进入 `in_review` 前，添加以下简短评论：

```text
结论：任务已完成自检，进入待验收。
实际完成：列出主要交付，不超过 4 项。
验证结果：列出测试、构建和关键页面检查。
注意事项/未完成：只列仍然有效的限制；没有则写“无”。
本地提交：填写提交哈希；未提交时说明原因。
下一步：说明用户验收后或下一个任务要做什么。
```

任务状态发生以下变化时，同步更新 `docs/CURRENT_STATE.md`：开始、进入待验收、用户验收完成、阻塞或取消。
