# 硅小智跨页面综合搜索设计

确认日期：2026-08-15

## 目标

把已经可用的硅小智语音搜索扩展到当前所有带搜索框的 PC 演示页面，并统一“搜索默认跨分类、分类可再次收窄”的行为。入口改为完整人物在上、独立名称牌在下，并支持拖拽后自动吸附浏览器左右边缘。

## 页面范围

- 企业首页 `/`：搜索企业商品并进入商品大厅综合结果。
- 企业商品大厅 `/products`：跨四个商品分区搜索。
- 供应商大厅 `/suppliers`：跨四个商品分区搜索并按企业去重。
- 产业服务 `/services`：跨六个服务分类搜索。
- 采购大厅 `/procurement`：搜索采购需求，并启用产品类型、交付地区和状态本地筛选。
- 订单履约中心 `/services/orders`：搜索订单并启用状态筛选。
- 个人消费首页 `/retail`：搜索七件零售商品并启用四个分类筛选。

## 统一交互

- 手动和语音提交关键词时，先清除当前分类或状态限制并显示本页综合结果。
- 用户随后点击分类或状态，可按“当前关键词 + 当前分类”收窄；再次点击当前分类恢复综合结果。
- 无关键词、无分类时显示本页全部本地演示数据；无匹配时显示明确空状态。
- 商品大厅使用 `section=all` 和 `keyword` 保存综合搜索状态；其他页面在本页更新结果。
- 供应商综合结果按企业去重，并合并跨分区主营品类和代表商品。

## 硅小智布局与拖拽

- 启动器采用上图下签，文字牌不覆盖人物。
- 使用 Pointer Events 区分点击与拖拽；超过小距离阈值后才视为拖拽，松手不误发展开。
- 拖动范围限制在浏览器可视区域；松手吸附到距离最近的左侧或右侧。
- 窗口变化时重新限制位置，位置保存在当前浏览器会话中，页面跳转后继续沿用。
- 面板根据入口所在侧对齐；入口靠近页面顶部时，面板显示在人物下方，避免超出视口。

## 不改范围

- 不覆盖移动端、详情页、发布表单、运营后台和数据大屏。
- 不实现多轮对话、后端 AI、真实搜索接口或跨页面混合搜索。
- 不改变现有商品、服务、订单和零售详情业务跳转。
