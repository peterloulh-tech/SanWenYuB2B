# 硅小智跨页面综合搜索实施计划

## 实施顺序

1. 扩展硅小智共享组件：上图下签、拖拽、贴边、视口限制和会话位置恢复。
2. 商品首页与商品大厅改为 `section=all` 综合搜索，分类卡支持再次点击取消。
3. 供应商目录增加跨分区去重合并，供应商和产业服务页接入语音与综合搜索。
4. 采购、订单和零售页把现有搜索与筛选控件改为真实本地筛选并接入语音。
5. 补充纯数据和源码结构测试，执行相关测试、静态资源检查、生产构建和差异检查。
6. 浏览器验证 1366×768、1440×900 和 1920×1080 的搜索、分类、拖拽吸附与无溢出表现。
7. 同步 Dashi、`CURRENT_STATE`、`PAGES_AND_FLOWS`、`REQUIREMENTS` 和 `CHANGELOG`，创建本地提交并进入待验收。

## 实现约束

- 继续使用浏览器 `SpeechRecognition` / `webkitSpeechRecognition`，不保存录音。
- 只使用 React 本地状态和现有演示数据，不增加状态库、搜索服务或第三方拖拽依赖。
- 保留现有页面结构、数据字段、详情入口和视觉体系，只修改搜索、筛选、空状态与硅小智附近代码。
