## PPT 内容判断

PPT 共 36 页，已逐页检查。

### 当前演示直接参考

- 项目定位与建设目标。
- 用户角色和业务闭环。
- PC 首页与移动端入口。
- 产品、商品详情、采购、报价、订单履约。
- 市场行情、供应链金融、运营后台和数据大屏。

### 只作背景了解

- 生产级本地部署和安全体系。
- 真实电子签章、支付、发票、WMS/TMS、IoT 和 GPS。
- 正式项目周期、团队、培训和长期运营机制。

除非用户明确提出，背景内容不进入当前静态页面开发范围。

## 新页面视觉方向

- 延续白色或淡蓝背景、深蓝主文字、蓝色主按钮、橙色重点数字。
- 保持轻边框、轻阴影、紧凑卡片和清晰网格。
- 保证核心业务入口显眼，减少装饰性信息。
- UI 原稿是方向参考，不要求逐像素复制；易用和首屏任务优先。
