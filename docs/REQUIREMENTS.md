# 总需求方向

## 1. 交易对象

平台不只交易成品鱼，应覆盖以下四类对象：

1. 实物商品。
2. 产业服务。
3. 供应信息。
4. 采购或服务需求。

## 2. 三文鱼全产业链范围

### 上游

- 鱼卵、鱼苗。
- 鱼药、疫苗、养殖设备。
- 鱼饲料及其他养殖物资。

### 中游

- 鲜活、冰鲜、冷冻整鱼。
- 去脏、分拣、切割和分装服务。
- 鱼块、鱼柳、鱼排、切片。
- 鱼骨、鱼头、鱼肠等副产物。
- 包装、检测、仓储、冷链和船运服务。

### 下游

- 鱼饼、烟熏产品和预制菜。
- 餐饮、商超、批发、电商和个人消费市场。

### 扩展品类

在三文鱼主线稳定后，可逐步扩展螃蟹、生蚝、虾、海马及其他海产品。

## 3. 基础业务能力

- 买家查找商品或服务。
- 卖家发布商品或服务。
- 买家发布采购需求或服务需求。
- 供应商在线报价并进行比较。
- 选择供应商、确认订单、查看订单和履约状态。
- 查看供应商、服务商和认证信息。

当前阶段只需静态演示和合理跳转，不要求真实提交或结算。

## 4. B2B 与 B2C

推荐“统一门户 + 双交易频道”：

- **企业交易**：批量、询价、起订量、合同、企业发票、账期和产业服务。
- **消费零售**：固定零售价、小包装、购物车、普通支付展示和个人售后。

频道切换与企业身份切换是两件事：

- 频道切换：企业交易 / 消费零售。
- 企业身份切换：采购方 / 供应方 / 服务商。

不应把 B2B 和 B2C 的价格、订单、结算方式直接混在同一个商品列表中。

## 5. 扩展展示能力

- 市场行情：地区、品类、规格、单位和数据日期。
- 新闻政策：国家、山东、日照、青岛、国企及行业专业来源。
- 项目进展：平台建设、产业合作、重点项目和活动动态。
- 运营后台：企业、商品、需求、订单和异常的静态看板。
- 数据大屏：交易额、交易量、区域流向、热门品类和运行状态。

## 6. 企业首页快捷入口规则

企业首页快捷功能区固定为两排，每排四项：

- 第一排：我要采购、我要卖鱼、我要找货、新闻政策。
- 第二排：产业服务、养殖供应、深加工品、其他海产。

鲜鱼产品不再占用快捷卡片，由“我要采购”“我要卖鱼”和采购大厅承接。养殖供应、深加工品和其他海产统一进入企业商品大厅 `/products`，并自动选中对应分区。市场行情不再占用快捷卡片，继续保留顶部导航及首页“今日市场”的更多入口。

企业商品大厅当前覆盖：

- 鲜鱼产品：整鱼、鱼柳、切片和副产物。
- 养殖供应：鱼卵鱼苗、鱼药疫苗、饲料和养殖设备。
- 深加工品：烟熏产品、鱼饼和预制菜。
- 其他海产：虾类、蟹类、扇贝和生蚝；使用企业规格、起订量和供应能力，不直接复用个人消费价格。

新闻政策快捷入口本轮只固定位置和阶段提示，资讯列表与详情仍由独立任务实施。

## 7. 当前阶段边界

实施优先级以 Dashi 当前任务和 `docs/CURRENT_STATE.md` 为准。

真实支付、真实融资、复杂审批、IoT、WMS/TMS 深度对接和生产安全体系只记录为后续方向。
