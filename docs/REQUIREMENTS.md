# 总需求方向

## 1. 交易对象

平台不只交易成品鱼，应覆盖以下四类对象：

1. 实物商品。
2. 产业服务。
3. 供应信息。
4. 采购或服务需求。

## 2. 三文鱼全产业链范围

### 上游

- 鱼卵、鱼苗。
- 鱼药、疫苗、养殖设备。
- 鱼饲料及其他养殖物资。

### 中游

- 鲜活、冰鲜、冷冻整鱼。
- 去脏、分拣、切割和分装服务。
- 鱼块、鱼柳、鱼排、切片。
- 鱼骨、鱼头、鱼肠等副产物。
- 包装、检测、仓储、冷链和船运服务。

### 下游

- 鱼饼、烟熏产品和预制菜。
- 餐饮、商超、批发、电商和个人消费市场。

### 扩展品类

在三文鱼主线稳定后，可逐步扩展鳟鱼、螃蟹、生蚝、虾、海马及其他海产品。鳟鱼作为品种归入“鲜鱼产品”，不新增第五个一级商品分区。

商品信息需区分三个维度：

- 品种：大西洋鲑、虹鳟等。
- 产品形态：冰鲜整鱼、鱼柳、切片、发眼卵、鱼苗、干品等。
- 产品产地/种源国家：挪威、美国、中国等；不得与供应商所在地或发货地混用。

鱼卵与鱼苗为两个独立品类，鱼卵按“枚”计价，鱼苗按“尾”计价。海马仅展示人工养殖干品和资质审核后询价，必须提示合法来源、经营资质与相关许可核验，不展示为无门槛普通鲜活海产。

## 3. 基础业务能力

- 买家查找商品或服务。
- 卖家发布商品或服务。
- 买家发布采购需求或服务需求。
- 供应商在线报价并进行比较。
- 选择供应商、确认订单、查看订单和履约状态。
- 查看供应商、服务商和认证信息。

供应商大厅在顶部标题横幅右侧提供搜索，并复用企业商品大厅当前可见的鲜鱼产品、养殖供应、深加工品三分类卡片。供应商目录从当前可见商品库按“供应商 + 分区”聚合，并补充山东万泽丰海洋开发集团有限公司、山东旭丰渔业有限公司、日照深海三文鱼产业协会三家平台承担主体。综合状态按企业去重并合并跨分类主营品类和代表商品，分类状态只显示对应分类记录。语音或手动提交关键词时默认取消分类选中并搜索全部企业，点击分类后按“当前关键词 + 当前分类”收窄，再次点击恢复综合结果，不增加“全部供应商”卡。企业卡片清晰呈现企业名称、所在地、实际主营品类、代表商品、演示商品数和企业主页入口；缺失 Logo 与资料明确显示待补充；1366×768 与 1920×1080 下不得产生整页横向滚动。

发布采购需求时，采购品类使用二到四个逐级出现的联动选择控件，依次表达大品类、细分品类、产品形式或品种、种源国家；所有层级按全分类树最长选项统一固定宽度，不使用密集完整路径长列表。养殖供应中的鱼卵、鱼苗使用四层联动，当前演示覆盖“大西洋鲑 / 挪威”和“虹鳟 / 美国”。品类控件下方提供“具体采购需求”多行自由输入，用于填写规格、等级、包装和交付批次等补充要求。采购品类、具体采购需求、需求数量、交付城市、截止日期和联系电话必填，联系邮箱选填；提交仅显示本页演示成功状态，不保存联系信息或创建真实采购单。

当前阶段只需静态演示和合理跳转，不要求真实提交或结算。

## 4. B2B 与 B2C

推荐“统一门户 + 双交易频道”：

- **企业交易**：批量、询价、起订量、合同、企业发票、账期和产业服务。
- **个人消费**：固定零售价、小包装、购物车、普通支付展示和个人售后。

频道切换与企业身份切换是两件事：

- 频道切换：企业交易 / 个人消费。
- 企业身份切换：采购方 / 供应方 / 服务商。

公共 PC 页头在品牌右侧常驻并排展示“企业交易”和“个人消费”，不使用“当前身份”下拉菜单。选中频道使用整块品牌蓝底和白字，未选频道使用浅色底和深色字；右侧频道内主导航继续使用蓝色文字与底部指示线，避免混淆频道状态和页面状态。点击企业交易进入 `/`，点击个人消费进入 `/retail`，现有统一账号、多身份和开通/入驻提示策略保持不变。

不应把 B2B 和 B2C 的价格、订单、结算方式直接混在同一个商品列表中。个人消费当前只展示冰鲜三文鱼、三文鱼加工品、三文鱼预制菜和三文鱼礼盒四类商品。

## 5. 扩展展示能力

- 硅小智语音搜索：在企业首页、企业商品大厅、供应商大厅、产业服务、采购大厅、订单履约中心和个人消费首页展示用户提供的本地卡通形象。入口采用完整人物在上、独立名称牌在下的布局，支持在可视区域内拖拽，松手后自动吸附最近的浏览器左侧或右侧，并在当前浏览器会话中跨页面保留位置。点击入口后使用浏览器提供的 `SpeechRecognition` 或 `webkitSpeechRecognition` 接收单次普通话语音，清理“帮我搜索”等常见口语前缀，将最终文字写入当前搜索栏并自动执行搜索。语音或手动提交关键词时默认取消当前分类或状态限制并显示本页综合结果；用户可随后点击分类收窄，再次点击恢复综合结果。商品大厅使用 `section=all` 与 `keyword` 恢复状态；供应商综合结果按企业去重。采购、订单和零售原有搜索与筛选控件必须产生真实本地演示结果。麦克风权限拒绝、无语音、无输入设备、网络错误和浏览器不支持时必须提供可恢复提示，原有手动搜索始终可用；平台不保存录音。当前目标为 macOS Chrome/Safari 与 Windows Chrome/Edge，实际能力以浏览器检测结果为准。
- 硅小智后续方向：多轮对话、渔业知识问答和站内数据统计不纳入一期。后续回答范围仅限渔业与平台公开数据，数据源只能来自匿名普通用户已可见的白名单字段或公开聚合接口，不得直接访问完整数据库、订单、联系方式、表单内容、用户行为、运营后台或其他内部数据；权限控制、领域拦截、来源与日期、演示数据标识和敏感字段隔离必须由服务端保证，不能只依赖提示词。
- 市场行情：使用与发布采购页一致的高对比选择控件提供品种、产品产地和产品形态筛选，并复用现有日期控件选择数据日期；品种中将虹鳟与银鲑作为两个独立选项和独立演示数据口径。重置为日期后的轻量文字操作。四项条件联动当日均价、成交量和采购需求；价格走势图复用前三项业务条件但不受数据日期影响，使用按需加载的 Apache ECharts，支持 7日、30日和90日切换、悬浮查看每日价格与响应式尺寸，不在图表底部重复展示当前均价和区间涨跌幅。移除热门需求方向与热门采购地区。行情页同级卡片标题统一为 20px/800；市场提示与采购快讯标题和正文统一以 16px 为阅读基线；全平台市场供需上方展示从右向左连续滚动的平台演示采购需求，三项指标使用单行“名称：数值单位”，名称 18px、数值 30px、单位 16px。所有数据为本地平台演示数据，不接真实行情接口；1366×768 与 1920×1080 不产生整页横向或纵向滚动。
- 新闻政策：资讯中心提供“综合、国家政策、时事新闻、行业资讯”四个分类；国家政策和时事新闻首批各展示 5 条国内政府或权威机构网站的近期有效内容，引入内容时须使用可核验的真实来源、日期和来源说明。
- 运营后台：企业、商品、需求、订单和异常的静态看板。
- 数据大屏：展示交易额、交易量、区域流向、产地排行、销售地区、重点采购商、规格需求与订单履约状态。顶部六项 KPI 保留“标题、核心数字、较昨日”三层结构，标题、数字、单位和昨日对比均设置清晰字号下限与高对比颜色；六张卡片使用统一内边距、固定图标列、固定文字起点和统一标题/数值/比较行位，累计三项保留不可见的比较行高度以维持基线，不按各自内容宽度独立居中。今日三项核心数字使用温和金橙色，累计三项保持暖白色，不新增“平台演示数据”标识。实时成交播报、表格与排行榜正文以 14px 为 1366×768 阅读基线；热门产地 TOP5 必须使用挪威、智利、中国、法罗群岛、加拿大等产地维度数据，不能混入商品名称。热门产地 TOP5 与热门规格需求 TOP5 的数值行不重复显示“吨”，统一在各自标题栏右侧标注“单位：吨”。近30日成交均价使用可悬浮查看日期与均价的 ECharts 折线图，近30日交易额使用可悬浮查看日期与金额的 ECharts 柱状图；日期轴显示清晰首尾与关键刻度，不保留手写 SVG 和大面积无效留白。热门规格需求 TOP5 每行先并排展示排名、规格和总量，再显示细比例条。原采购商结构替换为订单履约状态环形图，展示待确认、待发货、运输中、已完成占比，圆环中心订单总数与顶部今日订单同步。全国交易流向地图保留以日照为中心的静态连线，并以错峰发光粒子沿线路向各地区动态移动。右下角不展示平台运行状态，改为三条本地演示供求信息，使用大字号单行四区布局并排展示“供/求、商品名 + 产地或目的地、数量单位、时间”，三行等高铺满面板，每约 2.8 秒循环更新；标题必须标注“演示数据”和“模拟实时更新”，不接真实消息推送。1366×768 与 1920×1080 下不得出现整页横向或纵向滚动、文字裁切或模块重叠。
- 企业公共导航：企业页面右上角使用“运营大屏”按钮进入 `/data-screen`；帮助中心入口位于公共页脚，与关于平台、服务说明、运营后台和隐私政策同行显示。

## 6. 企业首页快捷入口规则

企业首页快捷功能区固定为两排，每排四项：

- 第一排：我要采购、我要卖鱼、我要找货、新闻政策。
- 第二排：产业服务、养殖供应、深加工品、溯源查询。

鲜鱼产品不再占用快捷卡片，由“我要采购”“我要卖鱼”和采购大厅承接。养殖供应、深加工品进入企业商品大厅 `/products` 并自动选中对应分区；溯源查询进入 `/traceability`。市场行情不占用快捷卡片或独立首页面板，通过顶部导航进入。原“其他海产”快捷卡代码注释保留，当前不展示。

八张快捷卡片的标题为 18px，说明文字为 14.8px，均比先前增加 2px；标题与说明之间统一增加 2px 上间距。“我要卖鱼”和“养殖供应”使用用户最终提供的透明圆形 PNG 图标，在卡片内固定为 50×50px，不得显示白色方形背景或被文字压缩。首页底部“认证供应商、采购企业、累计交易量、覆盖城市”按用户最新提供的图1至图4分别使用蓝色人物、绿色企业、橙色增长和紫色定位透明 PNG 图标。

企业首页“热门现货”使用统一企业商品库中的 8 项演示商品，不维护与详情分离的旧商品副本。卡片展示名称、产品产地、产品形态、规格和正确计价单位的参考价，并从右向左约 32 秒一轮无缝循环；鼠标悬停或键盘聚焦时暂停，系统开启减少动态效果时停止自动滚动并只展示可手动浏览的首组。每张卡片必须进入名称、产品产地和产品形态一致的商品详情，且不得造成整页横向滚动。

企业首页快捷入口下方的核心信息区与第二排四张快捷卡片共用四等分栅格：热门现货横跨前两列，左右边界分别与“产业服务”和“养殖供应”的外边界对齐；最新采购需求与“深加工品”左右边界对齐；优质供应商与“溯源查询”左右边界对齐。三个面板的“更多”统一使用 14px 清晰文字。采购需求与供应商记录使用两行大字信息布局，商品名和公司名独占首行并使用 15px 字号；第二行左侧分别展示“数量 · 目的地”和主营品类，右侧在操作前的留白区展示完整截止日期或城市，辅助信息与操作文字不低于 12px。热门现货滚动、采购需求和供应商数据及跳转保持不变。

企业商品大厅当前可见范围：

- 鲜鱼产品：三文鱼整鱼、鱼柳、切片、副产物和虹鳟整鱼。
- 养殖供应：鱼卵、鱼苗、鱼药疫苗、饲料和养殖设备；鱼卵与鱼苗分别提供挪威、美国种源演示商品。
- 深加工品：烟熏产品、鱼饼和预制菜。
- 原“其他海产”分区及虾、蟹、扇贝、生蚝、人工养殖海马干品、西施舌代码必须注释保留，不在当前页面展示。

企业商品大厅不得使用纯文字信息卡替代商品展示；鲜鱼产品、养殖供应和深加工品统一使用顶部大图与下方企业采购信息卡片。三张分区卡可全部不选，显示 15 项全部商品或跨分区关键词结果；提交关键词后进入综合结果，点击分区按当前关键词收窄，再次点击恢复综合结果。快捷分类卡与供应商大厅共用选中态，使用加深浅蓝底和 2px 蓝色边框。快捷卡下方不再独占一行显示当前分类名称和静态演示商品数量，商品网格直接上移；企业采购价提示保留在网格下方分页栏。综合、分类和搜索结果每页最多显示 8 项，使用四列两行网格；切换分类或提交搜索后回到第 1 页，页码通过 URL 恢复。“整鱼、鱼柳”等商品细分类从图片左下角移到商品名称行右端，不显示“平台认证”或所属大分类标语，也不使用商品类别图标。商品卡继续保留原顶部图片尺寸、上图下文结构、四个浅色详情块、圆角、阴影和按钮尺寸；规格/起订量与参考价/供应能力分别并排，每列使用固定字段宽度，字段文字左对齐，冒号上下固定对齐。品种与产品产地为 12px；供应商和所在地为加深颜色的 13px；详情字段名为 12px，字段值为 14px。查看商品和立即询价文字继续保持 1366 宽度下 12px、宽屏 13px。详情区适度收紧但不紧凑：两行详情块间距为 6px，详情到按钮为 8px，卡片底部保留约 9—11px。超长字段保持单行省略并提供完整悬停提示。商品卡片图片必须与商品信息匹配，并保留商品名称、品种、产品产地、规格、参考价、起订量、供应能力、供应商、供应商所在地与询价操作；商品详情继续分开展示产品产地/种源国家和供应商所在地，并按商品显示正确计价单位。

新闻政策快捷入口进入资讯中心；“国家政策”和“时事新闻”各收录 5 条国内官方网站内容，“行业资讯”收录微信公众号“壹渔业”最近 20 篇文章，按每页 6 篇分页展示，详情保留来源、日期、摘要、内容分类和标签。官方网站内容提供原文链接；公众号文章无法取得稳定原文链接时不得伪造链接，应展示公众号名称、ID 和微信内检索方式。

## 8. PC 低滚动与视觉一致性基线

- 所有 PC 页面在 1366×768 与 1920×1080 下不得产生整页横向滚动；列表、工作台和高频操作页优先单屏或低滚动，商品详情、资讯详情及其他长内容允许必要的纵向浏览。
